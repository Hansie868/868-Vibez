# MediaSuite V3 — All 4 Phases

A local-first PWA music/DJ workstation generated by `install-mediasuite-v3-all-phases.sh`.

## Run

```bash
bash install-mediasuite-v3-all-phases.sh
cd media-suite-v3
npx serve .
```

## Included Phases

### Phase 1 — Universal Library Database
- IndexedDB stores for tracks, metadata, waveforms, crates, sessions, cue points, settings, artwork.
- Track fingerprint IDs using path + file size + last modified.
- Folder scanner using the browser File System Access API.
- Expanded metadata editor.

### Phase 2 — Waveform Cache + Harmonic Matching
- AudioBuffer peak extraction.
- IndexedDB waveform caching.
- Camelot key compatibility detection.
- Dynamic perfect, harmonic, and tempo match highlighting.

### Phase 3 — Smart Crates + Search + Recommendations
- Smart crate schema with rule sets.
- BPM, key, genre, energy, and favorite filters.
- Global search with basic syntax.
- Deck-based recommendation scoring.

### Phase 4 — DJ Performance + Analytics
- Dual deck loading.
- Cue point saving.
- Session recorder.
- Local analytics and library health report.

## Notes

- This app is fully client-side and local-first.
- Folder access works best in Chromium browsers.
- Some browser/mobile environments may require re-opening the folder after refresh due to permission rules.
